# Primitive DB

База данных, написанная на Python.

## Установка и запуск

Для запуска проекта выполните:

```bash
uv run database



## Управление таблицами
База данных поддерживает следующие команды:

create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> .. - создать таблицу.
Поддерживаемые типы: int, str, bool. Столбец ID:int создается автоматически.

list_tables - показать список всех таблиц.

drop_table <имя_таблицы> - удалить таблицу.

help - показать справку.

exit - выход из программы.


## Пример использования
text
Введите команду: create_table users name:str age:int
Таблица "users" создана со столбцами: ID:int, name:str, age:int

Введите команду: list_tables
- users

Введите команду: drop_table users
Успешно! Таблица с именем 'users' удалена
